1. 事業者について

Pearlwave（以下「本ゲーム」といいます）は、Android および iOS 向けのパズルゲームです。本ゲームは BringNext LLC（所在地：1021 E Lincolnway #9340, Cheyenne, WY 82001, United States、以下「当社」といいます）が提供しています。

本ポリシーに関するお問い合わせ窓口：contact@bringnextinc.com

2. 要点

  1. 本ゲームには、アカウントも、ログインも、当社のサーバーもありません。進行状況、設定、購入記録は、お使いの端末のみに保存されます。
  2. 本ゲームは13歳以上の方を対象としています。子どもを対象としたものではなく、年齢もおたずねしません（第4条）。
  3. 本ゲームでは、Google AdMob が配信する広告を表示します。ご自身の選択で視聴するリワード動画広告と、一部のレベルの合間に表示される短い全画面広告です（第5.2条）。広告を配信する広告事業者は、お使いの端末から一部の技術的なデータを受け取ります（第5条）。法令が許可を求める場合には、パーソナライズ広告は、お客様が許可した場合にのみ表示されます。許可しない場合も広告は表示されますが、パーソナライズされません。
  4. 法令上認められる場合に限り、また、法令が同意を求める場合（たとえば EEA、英国、スイス）にはお客様が同意した後にのみ、本ゲームは Google Firebase を使って、利用状況データとクラッシュデータを送信し、レベルの難易度に関する小さなリモート設定を受信します（第5.3条）。このデータはお客様の名前を示すものではなく、当社はこれを広告に利用しません。
  5. 当社は、お客様のデータを販売しません。バナー広告は表示しません。ランダムなアイテムの販売も行いません。本ゲームには無料の報酬の宝箱があり、中身はすでに解放済みのアイテムの中からランダムに決まります。開ける前に確率が表示され、現金やゲーム内通貨で購入することはできません。
  6. EEA、英国、スイスでは、広告、利用状況データ、クラッシュレポート、リモート設定が始まる前に本ゲームが同意をおたずねし、iOS では一度だけトラッキングの許可をおたずねします。これらの選択は、後から変更できます（第5.4条、第5.5条、第7条）。

3. お使いの端末に保存される情報

以下は本ゲームが作成し、お使いの端末にのみ保存される情報です。当社はこれらを受け取りません。

お使いの端末がアプリのデータをバックアップする場合（たとえば Android の自動バックアップや iCloud）、セーブデータがオペレーティングシステムによってそのバックアップに含まれることがあります。当社はこれらのバックアップを管理することも、確認することもできません。

4. 本ゲームの対象となる方

本ゲームは13歳以上の方を対象としています。13歳未満の子どもを対象としたものではありません。本ゲームは年齢をおたずねしないため、年齢によって広告、購入、データ収集が変わることはなく、すべてのプレイヤーが同じ機能を利用できます。

現在、本ゲームは、当社のサーバーに個人データを収集することはありません。お使いの端末の外に出るデータは、第5条に記載した広告サービスおよび分析サービスに送られるものだけです。当社は、13歳未満の子どもから個人情報を意図的に収集することはありません。保護者の方で、13歳未満のお子様が本ゲームを通じてデータを送信したことを知った場合は、contact@bringnextinc.com までご連絡ください。当社が保有する情報を削除し、残りについては第5条に挙げた事業者に削除を依頼します。

保護者の方は、Google ファミリー リンクまたは Apple のスクリーンタイムの機能を使って、お子様の端末での購入と広告を制限できます。

5. 端末の外に出る情報

本ゲームは、遊ぶためにインターネット接続を必要としません。情報がお使いの端末の外に出るのは、以下の場合のみです。

5.1 購入

購入の処理は、当社ではなく Google Play または Apple App Store が行います。当社がお客様のカード情報や支払情報を見ることはありません。購入された商品はストアから本ゲームに通知され、本ゲームはお使いの端末上でレシートを確認します。当社は購入情報を保存するサーバーを運営していません。各ストアのプライバシーポリシーをご確認ください。Google Play：https://policies.google.com/privacy、Apple：https://www.apple.com/legal/privacy/。

5.2 広告

本ゲームは、2種類の広告を表示するために Google AdMob を利用しています。リワード動画広告は、報酬の内容が書かれたボタンをお客様がタップしたときにのみ表示されます。インタースティシャル広告は、レベルの合間に表示される短い全画面広告で、お客様が選ぶものではありません。本書作成時点では、レベル16以降かつ2回目以降のセッションから表示が始まり、3回勝つごとに表示され、直前の全画面広告から少なくとも3分あけ、1日最大6回までとし、敗北後やリワード広告の直後には表示しません。広告非表示の購入をされた場合や、いずれかの購入から7日間は表示されません。各広告の前には短い「すぐ戻ります」画面、後には感謝の画面が表示されます。これらは本ゲームの一部です。バナー広告や起動時の広告はありません。

広告がリクエストされると、Google は、お使いの端末から次のようなデータを受け取り、利用することがあります。IP アドレス、端末およびアプリの識別子（許可されている場合は Android の広告 ID または iOS の広告用識別子を含みます）、端末のモデルとオペレーティングシステム、アプリのバージョン、言語、広告とのやり取りに関する情報（表示、タップ、動画の視聴）。Google は、これらを、広告の選択と表示、広告の計測、広告の表示頻度の制限、不正の防止、および法的義務の履行のために利用します。Android では、本ゲームは広告ID権限（AD_ID）を宣言しているため、広告がパーソナライズされない場合でも、Google は広告リクエストとともに広告IDを受け取り、計測、頻度制限、不正防止に利用します。当社は、広告をコンテンツレーティング PG 以下に制限するよう Google に求めており、本ゲームおよびその広告リクエストを子ども向けとして指定していません。Google はこのデータについて独立した管理者として行動します。https://policies.google.com/technologies/ads および https://policies.google.com/privacy をご覧ください。

パーソナライズ広告は、お客様の広告用識別子を使用します。パーソナライズ広告は、法令が許可する場合にのみ表示され、法令がお客様の許可（第5.4条の同意メッセージおよび第5.5条の iOS のトラッキングの許可）を求める場合には、お客様が許可を与えた場合にのみ表示されます。許可がない場合も広告は表示されますが、パーソナライズされず、Google は上記の識別子を計測、頻度制限、不正防止のために引き続き利用することがあります。

5.3 利用状況データ、クラッシュデータ、リモート設定データ（Google Firebase）

本ゲームは、Google の製品である Firebase の3つのサービスを利用しています。Firebase Analytics（Google Analytics for Firebase）、Firebase Crashlytics、Firebase Remote Config です。これらは Google LLC（1600 Amphitheatre Parkway, Mountain View, California, USA）が提供し、EEA、英国、スイスのユーザーには Google Ireland Limited が提供します。Google は、Firebase データ処理およびセキュリティ条項（https://firebase.google.com/terms/data-processing-terms ）に基づき、当社のサービス提供者（処理者）として当社のためにこのデータを処理します。https://firebase.google.com/support/privacy および https://policies.google.com/privacy もご覧ください。

この3つのサービスは、本ゲームの同意の手順が実行されるまで、オフのままです。法令がお客様の同意を求める場合（たとえば EEA、英国、スイス）、お客様が同意するまで何も送信されず、拒否した場合や回答していない場合も何も送信されません。同意が必要とされない場合は、確認なしに開始されます。「設定」、「プライバシー」にあるスイッチ「利用データを共有」により、同意のメッセージが表示される人だけでなく、すべてのプレイヤーが、いつでもこれらをオフにできます。オフにする手順は同意の撤回と同じです（端末上の分析データがリセットされ、未送信のクラッシュレポートと Firebase のインストール識別子が削除されます）。

  1. Firebase Analytics。 本ゲームは、遊ばれ方を示すイベントを送信します。初回起動と最初の数分間のステップ、開始および終了したレベル（レベル番号、モード、勝敗、星、使用した手数と残りの手数、残りの目標、使用したブースターやアイテム、ゲーム内通貨で購入した手数、および後述の Remote Config による難易度設定）、開かれた画面（マップ、ショップ、水族館、デイリーチャレンジ）、獲得または消費したゲーム内通貨、デコレーションと報酬、週間目標、通知とリマインダーの選択（たとえば許可が与えられたかどうか、どのリマインダーから本ゲームが開かれたか）、提示および報酬が付与された広告（広告枠のみ）、完了した購入（商品名のみで、お支払いの詳細は含みません）、変更された設定（設定の名前）、セッションの長さと回数です。また、本ゲームはいくつかのユーザープロパティを設定します。インストールからの日数、勝利した最高レベル、購入したことがあるかどうか、通知の許可の状態、テストグループです。Firebase は技術的なデータを自動的に追加します。端末のモデル、オペレーティングシステムとアプリのバージョン、言語、接続から推定される国、初回起動の時刻、エンゲージメント時間です。Google は、Google アナリティクス 4 は IP アドレスをログに記録も保存もしないと表明しています。当社は Google シグナルを有効にせず、Analytics のために Android の広告 ID や iOS の広告用識別子を使用も収集もせず、Analytics を Google 広告やその他の広告製品と連携させず、ユーザー ID も設定しません。広告ストレージ、広告用ユーザーデータ、広告のパーソナライズに関する同意シグナルは、拒否に設定されています。
  2. Firebase Crashlytics。 本ゲームがクラッシュしたり、未処理のエラーが発生したりすると、Crashlytics は、スタックトレース、その時点のアプリの状態、端末のモデル、オペレーティングシステムのバージョン、メモリ、ストレージなどの端末の詳細、Crashlytics のインストール識別子（SDK が作成するランダムな番号）、および Firebase のインストール識別子を送信します。一部のネイティブのクラッシュでは、レポートを作成するためにメモリダンプが一時的に読み取られ、その後破棄されます。お使いの端末に保存されているものの、まだ送信されていないクラッシュレポートは、お客様が拒否した場合、同意を撤回した場合、または「ローカルデータを削除」を使用した場合に削除されます。
  3. Firebase Remote Config。 本ゲームは、起動時に、また最大で3時間に1回、Firebase にいくつかの設定を求めます。リクエストには、Firebase のインストール識別子、アプリ名とバージョン、言語、国コード、タイムゾーン、オペレーティングシステムのバージョン、SDK のバージョンが含まれ、さらに Analytics がオンであるため、上記のユーザープロパティと初回起動の時刻も含まれます。お客様の IP アドレスは、あらゆるインターネットのリクエストと同様に Google に届きます。当社は Remote Config を次の2つの目的にのみ使用します。キャンペーンのレベルの手数を一定の小さな幅で変更すること（プレイヤー全体の行動から難易度のバランスを取るため）、および問題を起こしている機能をオフにすることです。新しい機能をオンにすること、価格を変更すること、お客様がどなたであるかによって異なる内容を表示することはできません。設定はお使いの端末に保存され、次のリクエストが成功するまで再利用されます。
  4. Firebase のインストール識別子。 Firebase は、本ゲームのインストールごとにランダムな識別子を作成します。これはお客様の名前を示すものではなく、Google は、これが個人や物理的な端末を一意に識別するものではないと表明しています。Crashlytics と Remote Config がこれを使用します。お客様が拒否した場合、同意を撤回した場合、または「ローカルデータを削除」を使用した場合、本ゲームはその削除を Firebase に依頼し、保存されている設定を削除します。その後、Google は、これに結び付いたデータを、稼働中のシステムとバックアップシステムから180日以内に削除します。新しい識別子は、再度同意が与えられた後にのみ作成されます。

当社はこのデータを、不具合の発見と修正、レベルの公平性の向上、および本ゲームの改善のために利用します。当社は、お客様の氏名、メールアドレス、電話番号、連絡先、写真、マイク、正確な位置情報を収集せず、このデータを広告に利用することもありません。

5.4 同意管理ツール

一部の地域（たとえば EEA、英国、スイス）では、広告または分析が始まる前に、本ゲームは Google の User Messaging Platform による同意メッセージを表示します。本ゲームは、起動のたびに、同意に関する情報の更新が必要かどうかを確認し、お住まいの地域の規則で必要とされる場合にのみ、メッセージを再度表示します。広告は、同意の手順が実行された後にのみリクエストされます。同意された場合、広告はパーソナライズされることがあります。同意されない場合も広告は表示されますが、本ゲームはリクエストを非パーソナライズとして送信します（第5.2条）。たとえばオフラインなどで同意に関する情報を読み込めない場合、読み込めるようになるまで、本ゲームは広告をリクエストしません。利用状況データ、クラッシュレポート、リモート設定（第5.3条）は、お客様の選択に従います。拒否された場合、これらは送信されず、リモート設定のリクエストも行われません。Google はお客様の選択をお使いの端末に保存するため、起動のたびにたずねられることはありません。この選択肢が必要とされる場合には、「設定」、「プライバシー」、「広告の選択」で、いつでも選択を変更できます。

5.5 iOS のトラッキングの許可

iOS では、本ゲームは、最初の広告がリクエストされる前に一度だけ、パーソナライズ広告を表示するために広告用識別子を使用してよいかどうかをおたずねします。Apple はこれをトラッキングと呼んでいます（App Tracking Transparency のプロンプト）。許可しない場合、iOS は本ゲームに広告用識別子を渡さず、広告はパーソナライズされません。EEA、英国、スイスでは、このプロンプトと第5.4条の同意メッセージの両方が表示されることがあります。これらは別々の選択です。iOS がプロンプトを表示するのはインストールごとに一度だけで、回答はいつでも iOS の「設定」、「プライバシーとセキュリティ」、「トラッキング」で変更できます。本ゲームは、すでにたずねたことだけを記録します（第3条）。

5.6 レビュー

本ゲームは、ストアの標準的な評価画面を一度だけ表示するよう、ストアに依頼することがあります。評価およびお客様が書いたテキストは、本ゲームではなくストアが取り扱います。

5.7 リンク

本ポリシー、利用規約、サポートへのリンクは、ブラウザで開きます。これらのサイトには、それぞれのポリシーがあります。

6. 当社が行わないこと

  1. アカウントの作成をお願いすることはありません。
  2. お客様の個人データを販売しません。13歳未満の子どもから個人データを意図的に収集することもありません。
  3. お客様の連絡先、写真、ファイル、カメラ、マイク、カレンダー、正確な位置情報にアクセスしません。
  4. プロモーション目的の通知を送りません。リマインダー通知が購入を宣伝することはありません。
  5. 年齢をおたずねせず、年齢の設定も保持しません。
  6. Firebase には Google シグナルも広告用識別子も使用せず、Firebase を広告製品と連携させることもありません（第5.3条）。

7. お客様の選択と権利

  1. ローカルデータの削除。 「設定」、「プライバシー」、「ローカルデータを削除」で、端末上の進行状況と設定が消去され、Firebase の分析用識別子がリセットされ、未送信のクラッシュレポートが削除され、インストール識別子を削除するよう Firebase に依頼します（第5.3条）。広告事業者や分析事業者がすでに保有しているデータは消去されません。それについては、5番をご利用ください。

10. データの保存期間

  1. お使いの端末上：ローカルデータを削除するか、アンインストールするまで。
  2. Firebase Analytics：イベントデータは14か月間保持されます。これは、Google がこの種のプロパティに提供している最長の期間です。Google がそこから作成し、識別子を含まないレポートは、それより長く保持されることがあります。
  3. Firebase Crashlytics：クラッシュデータは90日間保持され、その後、Google は稼働中のシステムとバックアップシステムからの削除を開始します。
  4. Firebase のインストール識別子と Remote Config のデータ：本ゲームがその識別子を削除するまで（お客様が拒否した場合、同意を撤回した場合、または「ローカルデータを削除」を使用した場合）。その後、Google は、その識別子に結び付いたデータを180日以内に削除します。そうならないままアンインストールされた場合、Google は、一定期間使用がないとインストール識別子を削除します（本書作成時点では270日）。
  5. 広告事業者のデータ：第5.2条にリンクした事業者自身のポリシーに従って保持されます。
